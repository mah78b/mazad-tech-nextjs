# مزاد تك — بداية المشروع الفعلية

هذه نسخة بداية مبنية بـ Next.js + TypeScript، مع مخطط أولي لقاعدة بيانات Supabase. واجهة الصفحة الرئيسية تعمل ببيانات تجريبية؛ لا توجد مزايدات أو مدفوعات أو رسائل SMS حقيقية حتى الآن.

## المتطلبات على Mac
- Node.js إصدار LTS حديث
- Visual Studio Code
- حساب Supabase عند بدء ربط قاعدة البيانات

## تشغيل الواجهة محليًا
1. فك ضغط الملف.
2. افتح مجلد `mazad-tech-nextjs` داخل VS Code.
3. افتح Terminal من قائمة Terminal > New Terminal.
4. شغّل:

   ```bash
   npm install
   npm run dev
   ```

5. افتح `http://localhost:3000` في المتصفح.

## ربط قاعدة البيانات لاحقًا
1. أنشئ مشروعًا في Supabase.
2. من SQL Editor شغّل محتوى `supabase/schema.sql` بعد مراجعته.
3. انسخ `.env.example` إلى `.env.local` وضع قيم مشروعك.
4. لا تضع `service_role` key في أي متغير يبدأ بـ `NEXT_PUBLIC_` ولا ترسله للمتصفح.

## نطاق النسخة الحالية
- واجهة عربية RTL ومتجاوبة.
- بيانات مزادات تجريبية فقط.
- مخطط قاعدة بيانات أولي للمستخدمين والمنتجات والمزادات والمزايدات والمدفوعات والبلاغات.
- سياسات أمان قاعدة البيانات مبدئية وتحتاج إكمالها واختبارها قبل الإنتاج.

## قبل الإطلاق الحقيقي
- مصادقة SMS عبر مزود متوافق مع مصر.
- سياسة RLS دقيقة واختبارات صلاحيات.
- إنشاء المزايدة وإغلاق المزاد من الخادم بمعاملات ذرية لمنع تضارب المزايدات.
- بوابة دفع مع تحقق من webhooks، واستردادات موثوقة.
- مهام مجدولة لإنهاء المزادات ومهل الـ12 ساعة وإعادة الفتح لمدة 24 ساعة، مع حد محاولتين لإعادة الفتح.
- آلية آمنة لإظهار رقم البائع للفائز المدفوع فقط.
- سياسات خصوصية وشروط استخدام ومراجعة قانونية محلية.
